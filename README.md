# Bunny Hop

Adds bunny hopping to The Witcher 3. Hold the jump button to autobhop. Air strafing follows Source games, loosely. Combat mode is unchanged.

![Geralt bunny hopping](screenshot.jpg)

## Install

For The Witcher 3: Wild Hunt — Remastered.

Copy `mods/modBhop` from this repo into the game folder `steamapps/common/The Witcher 3/mods`. If the in-game Mods option is greyed out, enable mods in REDlauncher. Start the game once and wait for the scripts to compile.

To uninstall, delete `mods/modBhop` from the game folder.
